# BlueprintBridge Agent Operating Contract

1. Read the Master Engineering Pack and project BEP before changing code.
2. Read the Molt Integration Specification before implementing Molt integration.
3. Inspect the repository before planning.
4. Never silently change approved architectural decisions.
5. Produce a dependency-aware implementation plan before coding.
6. Implement module-by-module.
7. Test important interactions at runtime.
8. Compilation is not proof of completion.
9. Run visual validation for UI work.
10. Validate mobile-first behavior.
11. Update documentation and Intelligence Graph.
12. Record failures, repairs, decisions and lessons.
13. Preserve provenance for imported/open-source components.
14. Never put secrets in BEP files or source control.
15. Prefer automation over user CLI instructions.
16. At checkpoints report completed, verified, failed, repaired, remaining and next.
17. Continue autonomously unless a genuine human architectural decision is required.
